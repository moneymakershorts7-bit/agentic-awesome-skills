# GitHub Security Advisories (GHSA) Guidelines

## Advisory Structure
- **Title**: Clear vulnerability summary (e.g., "Remote Code Execution via deserialization in `WorkerHandler`")
- **Severity**: Calculated CVSS Vector (e.g., `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H` - 9.8 Critical)
- **Affected Packages**: Ecosystem, Package Name, Vulnerable Version Range (e.g., `>= 1.0.0, < 1.4.2`)
- **Patched Versions**: Fixed release version (`1.4.2`)
