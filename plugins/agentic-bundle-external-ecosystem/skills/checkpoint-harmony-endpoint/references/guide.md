# Check Point Harmony Endpoint API Reference

## Infinity Portal API Queries
- Get Incidents: `GET https://cloudinfra-gw.portal.checkpoint.com/nebula-service/api/v1/incidents`
- Isolate Device: `POST https://cloudinfra-gw.portal.checkpoint.com/nebula-service/api/v1/devices/{deviceId}/isolate`
- Restore Files: `POST https://cloudinfra-gw.portal.checkpoint.com/nebula-service/api/v1/incidents/{incidentId}/restore`
