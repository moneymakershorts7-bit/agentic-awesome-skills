# Popular Icon Collections & Namespaces

`better-icons` interfaces with over 150 open-source icon sets hosted by Iconify. The table below lists the most commonly used collections in production apps.

---

## Catalog by Style & Domain

| Prefix | Name | Dominant Style | Count | Best For |
| :--- | :--- | :--- | :--- | :--- |
| `lucide` | **Lucide Icons** | Outline (2px stroke) | 1,500+ | Modern React, Next.js, shadcn/ui, Tailwind interfaces. |
| `heroicons` | **Heroicons** | Outline / Solid / Mini | 300+ | Tailwind Labs official aesthetic, modern SaaS dashboards. |
| `tabler` | **Tabler Icons** | Outline (Stroke-based) | 5,000+ | Enterprise dashboards, rich data tables, analytics. |
| `mdi` | **Material Design Icons** | Solid / Outline / Rounded | 7,000+ | Android, Google Workspace, multi-state action controls. |
| `ph` | **Phosphor Icons** | Thin, Light, Regular, Bold, Fill, Duotone | 9,000+ | High-craft design systems requiring fine-grained weight control. |
| `ri` | **Remix Icon** | Line / Fill pairs | 2,800+ | Neutral, balanced UI elements with explicit line/fill state pairs. |
| `solar` | **Solar Icons** | Bold, Broken, Linear, Outline | 7,000+ | Premium fintech, modern web apps, trendy mobile interfaces. |
| `fa6-solid` | **Font Awesome 6** | Solid / Regular / Brands | 2,000+ | Broad compatibility, legacy migrations, universal recognition. |
| `simple-icons` | **Simple Icons** | Brand Logos | 3,000+ | Technology badges, OAuth buttons, social links, provider logos. |
| `radix-icons` | **Radix UI Icons** | Precision 15×15px | 300+ | Micro-controls, dropdown menus, context toolbars. |
