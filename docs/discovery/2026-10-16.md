During the monthly repository maintenance sweep (`skills-maintainer all` or `skills-maintainer review-discovery`):
1. **Review candidate worthiness:** Filter by Score >= 3 and Risk `SAFE`/`LOW`.
2. **Security scan:** Run `skills-maintainer review-discovery --audit`.
3. **Promote:** Run `skills-maintainer review-discovery --accept <id>` to move into active `skills/` or `plugins/`.
4. **Discard:** Run `skills-maintainer review-discovery --reject <id>` for low-quality or duplicate candidates.
