## Overview
hubmemory 是一个面向本机多 Agent 的共享记忆 Skill。它监听 Claude Code、Codex CLI / Desktop 等工具产生的会话文件，把事件统一归档到 ~/hubmemory，并提供实时状态、历史检索、日报、月报和长期记忆能力。
