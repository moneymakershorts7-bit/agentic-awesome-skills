# doc-driven-development

Candidate agent skill discovered on GitHub from [wbaxm2016/doc-driven-development](https://github.com/wbaxm2016/doc-driven-development).

## Overview
这是一套面向 AI 协作开发的过程方法。 它接上两头：表达出来、还没实现的，写成有出处、有验收的方向与任务；已经实现的，散落在代码、文档、提交和会话里，沉淀为可核对的事实——一句结论追得到需求、代码入口和那次提交。需求与途中冒出的创意，都不许只活在一次会话里。 功能的堆砌不是系统。从任意切入点出发，用方向把散落的功能接上线，走通一条路；路叠起来，系统被走遍——开发与验收才是系统级的。 代码只交代结果；当初面对什么问题、后来怎么做的，留在仓库里、可回溯。所以开发随心开始、随心结束；下一次，AI 先读现状，按约定动手，说做完了拿得出证据。后来者不用猜，更不必从头再来。 一处连带问题
