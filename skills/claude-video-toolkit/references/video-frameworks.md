# Claude Video Toolkit: Framework Catalog & Patterns

## Top Open-Source Frameworks for Agent Video Generation

1. **Remotion (`@remotion/cli`)**:
   - Write video using React components, HTML5, CSS animations, and Three.js.
   - Built-in bundle and SSR render engine with concurrency scaling.
2. **FFmpeg (`ffmpeg-python` / CLI)**:
   - Hardware-accelerated filterchains (`scale`, `crop`, `fps`, `colormatrix`, `overlay`).
   - Concat demuxer for seamless scene transitions.
3. **Motion Canvas**:
   - TypeScript programmatic vector animation engine designed for mathematical and technical explanations.
4. **Auto-Captions & Subtitle Engine**:
   - Word-level timing synchronization with Whisper / WhisperX.
   - Dynamic pop-in animations and glow text shaders via Aegisub ASS subtitles.
